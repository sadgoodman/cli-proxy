# Code of conduct

## The short version

Be decent. This is a small tool maintained in spare time; treat the people who
use it, report on it and contribute to it with the same patience you would want
in return.

Concretely, that means:

- Assume the person on the other side is acting in good faith.
- Critique code and ideas, not people. "This breaks X" is useful; "you clearly
  did not think" is not.
- Keep issues and pull requests on topic. Off-topic argument wastes the one
  resource this project has.
- Respect privacy. Traffic captures, URLs, tokens and certificate material
  posted in a bug report are other people's data — redact before you paste.
- Do not use the project's spaces to promote unrelated products or to harass
  anyone.

## Not acceptable

Harassment, insults, discrimination, sexualised comments, deliberate
intimidation, publishing someone's private information, and sustained
disruption of discussions.

## Scope

This applies to issues, pull requests, discussions, commit messages and any
other space associated with the repository.

## Reporting and enforcement

If someone is behaving badly, use GitHub's own tooling: the **Report content**
option on the offending comment or issue, or
[report abuse](https://github.com/contact/report-abuse) for anything more
serious. As the maintainer, I may edit or delete comments, close issues, block
accounts, or refuse contributions, in proportion to what happened.

Reports are handled privately. Nobody is expected to keep engaging with someone
who is making the project unpleasant.
