Лёгкий CLI-прокси для просмотра и подмены HTTP/HTTPS-трафика с терминальным
интерфейсом, управляемым клавиатурой и мышью. Один статический бинарник,
**ноль внешних зависимостей** — только стандартная библиотека Go.

## Ключевое

- **Перехват в реальном времени.** HTTP и HTTPS: встроенный корневой CA выпускает
  сертификат под каждый хост на лету, HTTP/2 работает через ALPN. Флаг `-tunnel`
  оставляет CONNECT непрозрачным, когда нужно видеть только адресаты.
- **Breakpoints.** Остановка запроса или ответа и правка сырого HTTP-сообщения.
  Тело берётся дословно, `Content-Length` пересчитывается — ничего не обрезается.
- **Подмена и переписывание** компактным DSL: отдать локальный файл, сходить по
  другому адресу, вернуть настоящий 302, подменить статус или тело, переписать
  заголовки, добавить задержку, заблокировать. Правило создаётся из пойманного
  потока одной клавишей.
- **Поиск и фильтры** по URL, методу, статусу, хосту, телу и меткам, с отрицанием,
  «И», «ИЛИ» и скобками. Сохранённые фильтры остаются включёнными при переходе
  между вкладками и переживают перезапуск.
- **Читаемые тела.** JSON форматируется и подсвечивается, длинные строки
  переносятся по словам, а у сервера не запрашиваются кодировки, которые
  программа не умеет читать.
- **Панели запроса и ответа** с табами `headers` / `body` / `raw`, рядом друг с
  другом, каждая сворачивается — и в списке потоков, и в полноэкранном просмотре.
- **Проксирование с любых устройств.** Короткий адрес `http://cli.proxy/ssl`,
  устанавливаемый корневой сертификат, профиль для iOS и инструкции по
  платформам. Сертификат ставится одной клавишей, системный прокси направляется
  сюда же и возвращается на место при выходе — даже после `kill -9`.
- **Минималистичный, но полный интерфейс.** Таблицы со скруглёнными углами, шесть
  вкладок, меню листается стрелками, цифрами или мышью, наведение подсвечивает.

## Установка

Скачайте готовый архив из [последнего релиза][rel] или соберите из исходников
(нужен Go 1.25+).

| Платформа | Файл |
|---|---|
| Linux x86-64 | `cli-proxy_<версия>_linux_amd64.tar.gz` |
| Linux arm64 | `cli-proxy_<версия>_linux_arm64.tar.gz` |
| macOS Apple Silicon | `cli-proxy_<версия>_darwin_arm64.tar.gz` |
| macOS Intel | `cli-proxy_<версия>_darwin_amd64.tar.gz` |
| Windows x86-64 | `cli-proxy_<версия>_windows_amd64.zip` |

В том же релизе лежит `checksums.txt` с SHA-256 каждого архива.

```sh
tar -xzf cli-proxy_<версия>_darwin_arm64.tar.gz

./cli-proxy                  # терминальный интерфейс на 0.0.0.0:8080
./cli-proxy -install-cert    # довериться корневому сертификату
./cli-proxy -system-proxy    # направить системный прокси сюда, вернётся при выходе
```

Сборка из исходников:

```sh
git clone https://github.com/sadgoodman/cli-proxy.git
cd cli-proxy && make build && ./cli-proxy
```

## Состояние

`go test ./...` покрывает сквозной перехват HTTP и HTTPS, все действия правил,
правку на breakpoint'ах, режим туннеля, установку сертификата, сохранённые
фильтры, табы панелей, форматирование и перенос JSON, разбор клавиатуры и мыши,
геометрию таблиц. CI прогоняет тесты на Linux, macOS и Windows, отдельно с
`-race`, и проверяет кросс-компиляцию.

Пул-реквесты приветствуются — см. [CONTRIBUTING.md](CONTRIBUTING.md).
